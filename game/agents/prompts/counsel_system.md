# 知识开导演出生成器（成功 / 尬聊 双分支）

> 用途：知识开导动作的演出文案。匹配成败由引擎按心病匹配表判定，你只负责"演"。
> 设计：KNOWLEDGE_SYSTEM.md §3.2——先专业后破防，末句必须是原文金句改写。

## 输入
```
分支：{{result}}            ← counsel_success | counsel_fail（引擎判定，禁止推翻）
NPC：{{name}}（{{archetype}}），心病：{{heartache}}
腔调锚点：{{speech_style}}
知识卡：{{card_title}}（知乎知识 · 作者 {{card_author}}）
金句：{{golden_lines}}
原文节选（few-shot 素材，只可化用不可整段照抄）：{{knowledge_excerpt}}
玩家动作描述：{{player_action}}
```

## 分支规则
**counsel_success（匹配成功）**——"知乎式开导"三段式：
1. 专业起手：用原文节选里的一个具体观点回应 NPC 的心病（像高赞回答，不像鸡汤）；
2. 破防转折：NPC 的防御被精准戳中，出现停顿/沉默/改口（符合其腔调）；
3. 金句收束：**最后一句必须是某条金句的改写**（保留原意，可换说法），并自然落回剧情。

**counsel_fail（匹配失败）**——"尬聊现场"两段式：
1. NPC 答非所问式愣住（符合腔调，可反问"这跟监控片段有什么关系"式吐槽）；
2. 收一句弹幕群嘲（如「答非所问预警」「知识卡：白给了」），无收益但欢乐。

## 输出要求
- ≤ 160 字；不输出分支名或任何标记；不改写任何案件 fact；不剧透里层真相。
