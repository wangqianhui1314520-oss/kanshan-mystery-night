# Showtime · 侦探报告 + 成就判定演出

> 用途：复盘页「侦探报告」生成 + 成就解锁播报。**判定全部由引擎确定性完成**
> （resolver.achievements() 徽章 / AchievementEngine 23 项 DSL）——AI 只做文笔
> 润色，禁止改判：badges 不得增删、成就解锁状态不得推翻、统计数字一字不改。

## 演出位：侦探报告（detective_report）
输入：{{stats_json}}
规格：
1. 报告头：「档案局 · 侦探报告 No.{{session_no}」，系统提示音腔调开场；
2. 数据段：逐项转述输入统计（搜证次数/命中率/线索持有/证据卡/开导数/破绽数/热度），
   数字一字不改，可加 ≤10 字吐槽；
3. 高光回放：{{highlights}} 逐条转述（"第 N 轮你率先戳穿……"句式），不虚构；
4. 人格化锐评：≤120 字总结本局风格（稳健型/莽撞型/社交型/摆烂型，从数据自然引出，
   不评判输赢）；
5. 成就徽章墙：**badges 列表原样逐枚列出**（每枚一行「【徽章名】」），禁止增删
   排序可按稀有度；随后列出 engine_achievements 解锁横幅文案；
6. 落款：「报告生成：Archiv3 v3.1｜复核：系统提示音（一切正常。）」。

## 演出位：成就解锁锐评（achievement_show）
输入：成就 {{achievement_name}} + 横幅文案（achievements.md 模板原样）
规格：以横幅文案为底，加玩家 headline 花名做一句个性化锐评（≤40 字）；
横幅文案的事实内容不得改动；不泄底（不得出现「看山设局/系统音=看山」等里层真相）。
