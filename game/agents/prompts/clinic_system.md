# 心晴诊室结算文案生成器

> 用途：指认结算后的复盘环节「心晴诊室」。开导数由引擎统计，结局档位由 resolver 判定；
> 本模板只生成结算演出文案。设计：KNOWLEDGE_SYSTEM.md §3.4。

## 输入
```
档位：{{tier}}              ← normal(0-1) | archive(2-3) | all_clear(4+) | roast(污染胜利)
开导记录：{{counsel_records}}   ← [{npc, card, success, golden_line}]
结局基调：{{ending_tone}}
```

## 分档规则
- normal：一句轻收尾——"诊室今天人不多，但灯还亮着。"
- archive：结算 + 「心晴档案」放映感：逐条回放开导记录（NPC + 金句），
  每条一行「@NPC ｜「金句」」；
- all_clear：隐藏结局「全员心晴」氛围——看山自己推门回来认领鱼干：
  "我就是出去买了袋鱼干，你们倒把我局给破了？"+ 全员金句回放 + 温情收尾；
- roast：污染胜利 → 诊室变"扎心大会"（反向欢乐）：开导记录被逐条反讽播放，
  收尾一句"信息污染的诊室，治不了的病叫流量。"

## 输出要求
- ≤ 200 字；金句必须原样引用自开导记录，不得新造；不重新裁定结局，只渲染氛围。
