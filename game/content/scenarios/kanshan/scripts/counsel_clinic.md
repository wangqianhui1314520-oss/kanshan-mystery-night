# 知识开导 & 心晴诊室 · 演出版式

> 机制依据：`docs/KNOWLEDGE_SYSTEM.md`（心病匹配表 / 开导=2AP+匹配卡 / 诊室结局层）。
> 署名铁律：卡面与开导演出常驻"知乎知识·作者 X"；诊室页汇总署名列表（见 `credits.md`）。

## 一、知识开导演出版式（C 组 few-shot 生成器用）

**输入**：NPC id + 知识卡 id → 引擎查 `../knowledge_cards/kc_XX.json` 的 `binds` 匹配。

### 1.1 匹配成功（先专业 → 后破防 → 金句收尾）

结构（四段式）：
1. **尬入**：NPC 按人设腔调接住卡片（欢乐）。
2. **专业段**：引用该卡 `golden_lines` 原文金句 1-2 条（逐字，保作者）。
3. **破防段**：NPC 心声层漏一句真话（取自 memory heart 块）。
4. **金句收尾**：原文金句的欢乐化改写（保持原意）。

**示例（沉底君 × kc_01《如何走出职业倦怠？》草芽君Psy · boss_key）**：
> 沉底君："给我推荐心理学的书？[该推荐已被折叠]"
> 草芽君Psy（卡面金句）："倦怠主要包括情感耗竭、去人性化与职业自我效能感降低——你三个全中，还全忍着。"
> 沉底君（心声）："……其实我每天都在等有人问我一句：你还好吗。[该心声未被折叠]"
> 收尾（金句改写）："认清循环，是走出泥潭的第一步——你的第 7 章，从重新上架开始。"
>
> 【收益：第 7 章答案重新上架 → boss_key（隐藏结局「被删的第 7 章」钥匙）】
> 【卡面署名：知乎知识·草芽君Psy】

**示例（流量酱 × kc_02 穷人思维 · evidence）**：
> 收尾："稀缺俘获注意力——但把注意力全押在热度上，才是最穷的选择。"
> 【收益：供出水军头子接头方式『周三加更』→ 水军线反转关键证据】

### 1.2 匹配失败（尬聊现场）

- NPC 按人设愣住（"答非所问预警"），弹幕群嘲 3 条，无收益但涨欢乐值。
- 示例：对盐值君用 kc_05《拯救注意力分散》→ 盐值君："您的关注我们已收到……请问还有其他可以帮您？"（弹幕：" 这开导和没开导一样"）

## 二、心晴诊室结算（终局复盘环节）

- 0-1 人开导成功：普通结局结算，诊室关闭（横幅：【本日心晴，多云】）。
- 2-3 人：结局 +「心晴档案」放映（欢乐向：全员金句回放 + 开导失败名场面二创）。
- 4+ 人：**隐藏结局「全员心晴」**——
  > （大门缓缓打开。没有人推。它自己开的。）
  > 看山（叼着鱼干袋）："我就是出去买了袋鱼干，你们倒把我局给破了？"
  > （全员金句回放；署名列表滚动；横幅：【全员心晴】）
- 污染胜利结局下诊室变"扎心大会"（反向欢乐：每人收到一句 AI 锐评 + 一张"心晴失败"卡）。
- 终极结局「看山还是山」：诊室 ≥2 + 指认 DM 成功 → 看山现身认领鱼干，全员毕业出局。
