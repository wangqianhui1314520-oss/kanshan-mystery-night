# 大型化设计：知乎身份系统 + 多人同场 + 侦探报告

> 需求：把 0.7.2 新能力（用户资料 API / creator API）用到游戏里；游玩机制继续优化完善，做成大型剧本杀。
> 原则：单人体验始终是保底路径（评委一人可通关）；所有新系统可裁剪、分层交付。
> 关联：CONTRACTS.md（v2.1）、GAME_DESIGN_V3.md、KNOWLEDGE_SYSTEM.md、DM_BOSS_DESIGN.md。

## 一、知乎身份系统（0.7.2 新 API 落地）

### 1.1 登录与侦探证
- 游戏内「知乎登录」→ OAuth（回调地址以活动页登记为准）→ F 后端换 access_token → **`GET https://openapi.zhihu.com/user`**（0.7.2 新接口）→ 取 `fullname / headline / avatar_path / uid`；
- AI 生成**《求真档案局特聘侦探证》**：证件照=玩家知乎头像、编号=uid 后 6 位、警衔=AI 依 headline 起的欢乐花名（如简介是"码农"→「调试人生司司长」）；
- **个性化台词彩蛋**：路人甲认出你——"等等，你简介写着'XXX'？大佬怎么也被锁进来了"。由 AI 依 headline 生成，每人不同 → 评委截图传播点。
- 隐私红线：只用公开三件套（昵称/头像/headline）；`email/phone_no` 字段一律忽略；除 session 外不落盘；产品说明如实声明。

### 1.2 画像模式（可选增强，默认关）
- `question recommend` 画像模式（creator 额度组）→ 玩家兴趣画像 → 只影响**彩蛋层**（弹幕梗、热搜词条向玩家兴趣倾斜），不进核心推理，保证公平与额度安全（未实名 10 次/日）。

## 二、多人同场模式（"大型"的核心）

| 模式 | 人数 | 说明 |
|---|---|---|
| 单人 | 1 | AI 扮演其余 7 人 + DM（评委保底路径，不可裁） |
| **联机同场** | 2-5 | 好友房间码进房，**每人扮一个角色**，AI 补齐空位 + DM 主持 |
| 观战 | 不限 | 旁听视角（直播/评委预览用） |

- 联机玩法变化：真人圆桌发言按序列主持；**真人私聊**（互坑比 AI 狠，欢乐核心）；行动点各算各的；投票聚合真人+AI；
- 阵营分配按人数动态配置（引擎 faction 分配器）；任一真人掉线 → AI 无缝接管该角色（一致性守卫保证口风不变）；
- 技术落点：F 的 WS 房间已具备，B 增加房间级阵营分配器，C 增加"真人发言 vs AI 角色"的对话混合调度。

## 三、侦探报告 + 成就（传播系统）

- 终局后 AI 生成**《侦探报告》**：推理评分（truth_node 覆盖度）、高光操作回放（"第 3 轮你率先戳穿监控删除"）、人格化锐评、本局成就徽章；
- 成就（D 文案）：「看山还是山」（指认 DM 成功）/「心晴医师」（开导 4+）/「带节奏之王」（污染胜利）/「鱼干守护者」（全线索收集）/「防折叠斗士」等；
- **分享卡**：报告+徽章+结局海报由前端 Canvas 合图（logo_badge + scene_exterior + 数据），保存/截图分享。注意：知乎开放平台**无写入接口**，不做"一键发布"，只做图片导出。

## 四、机制补完（打磨清单）

1. **动态难度正式化**：Judge Agent 每幕结算 → 下幕线索发放梯度（新手多提示 / 老手模糊化）+ 热度过门阈值微调；
2. **防卡死提示**：同一线索 2 轮无进展 → DM 发"档案局备忘录"（点方向不泄底）；
3. **二周目**：通关节日解锁「污染阵营视角」重玩（同一真相、任务反转，内容复用 90%）；
4. **成就数据**进 session_store，跨局统计（本地）。

## 五、契约增量（已同步 CONTRACTS）

- routes：+ `GET /api/profile/me`（登录后资料）、`POST /api/session/{id}/login`（OAuth code 换 token 入 session）；
- events：+ `login_success / dossier_ready / achievement_unlocked`；mode 增 `party`；
- 窗口影响：C 加侦探证/报告生成器；F 加 OAuth 交换与 profile 代理；E 加登录按钮+侦探证 UI+报告/分享页；D 加成就文案；B 加 party 房间阵营分配；
- 交付分级：P1=侦探证+单人全流程（必做）；P2=联机同场；P3=画像彩蛋+二周目（可裁）。
