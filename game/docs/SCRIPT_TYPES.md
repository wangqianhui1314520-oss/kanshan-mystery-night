# 剧本杀类型与选题（比赛适配分析）

> 知乎黑客松2026·叙事内容创作赛道评审维度：创意创新性、Demo 完成度、知乎 API 合理运用、社区价值、落地可行性。
> 本文件给出 6 个适合 AI 原生剧本杀的类型，标注比赛适配度与推荐顺序。

## 类型速览

| 类型 | 一句话定位 | 比赛适配度 | 开发难度 | 推荐 |
|---|---|---|---|---|
| 社会派悬疑推理 | 贴近现实的连环案，纯逻辑破案 | ★★★★★ | ★★★☆☆ | 首推 |
| 都市情感 | 爱与秘密的修罗场，重对话演绎 | ★★★★☆ | ★★★☆☆ | 推荐 |
| 古风权谋 | 庙堂江湖双线，阵营与身份迷局 | ★★★★☆ | ★★★★☆ | 推荐 |
| 科幻脑洞 | 赛博都市的记忆犯罪，设定先行 | ★★★★★ | ★★★☆☆ | 差异化首选 |
| 恐怖惊悚还原 | 灵异氛围还原真相，惊吓+推理 | ★★★☆☆ | ★★★☆☆ | 备选（注意尺度） |
| 阵营机制本 | 多阵营对抗+任务技能，游戏性最强 | ★★★★☆ | ★★★★★ | 有实力再上 |

---

## 类型一：社会派悬疑推理本（首推）

**定位**：真实案件感，玩家扮演调查者/嫌疑人，靠搜证与盘问还原真相。
**核心玩法**：连环失踪案 → 多人证词互相矛盾 → 搜证发现伪装线索 → 指认真凶。
**AI 亮点**：
- 证人 NPC 会说谎、会隐瞒，玩家靠提问交叉验证（推理裁判 Agent 给逻辑评分）
- 搜证系统：地点 × 条件 → 动态线索（直答 Agent 生成细节，引擎控制发放）
- 知乎热榜 API：案件原型可挂钩真实社会议题讨论，增强"知乎感"
**盐言 IP 适配**：盐言悬疑/刑侦类小说（高热度，版权现成）
**比赛适配**：推理闭环可验证，评审最容易理解"AI 不只是聊天"；Demo 稳定度最高。

## 类型二：都市情感本

**定位**：一桩旧案牵扯出情感纠葛，重角色演绎与秘密交换。
**核心玩法**：6 人同学会重聚 → 旧爱、背叛、失踪案交织 → 私聊交换秘密 → 还原真相。
**AI 亮点**：
- NPC 情感记忆：记得你之前说的话，态度随关系变化（短期+长期记忆）
- 私聊系统：1v1 对话，信息不对称制造张力
- 直答 Agent 生成情绪化对话，角色一致性由角色卡锁定
**盐言 IP 适配**：盐言都市情感/家庭伦理小说
**比赛适配**：AI 角色扮演展示力最强，"会演"比"会推理"更直观。

## 类型三：古风权谋本

**定位**：庙堂与江湖双线，身份与阵营的罗生门。
**核心玩法**：朝堂命案 → 各怀秘密的臣子（玩家）→ 搜证+试探 → 指认幕后主使。
**AI 亮点**：
- 世界观 RAG：盐言古风小说设定入库，AI 生成符合时代语境的描写
- 阵营系统：NPC 分派系，玩家的选择改变势力平衡
- 知乎搜索 API：可检索历史典故辅助场景生成
**盐言 IP 适配**：盐言古风/仙侠头部 IP（改编自带粉丝）
**比赛适配**：世界观与美术呈现力强，适合做视觉冲击力强的 Demo；开发量偏大。

## 类型四：科幻脑洞本（差异化首选）

**定位**：设定先行——记忆可以被篡改的赛博都市，每个人记得的"真相"都不可靠。
**核心玩法**：记忆芯片案 → 玩家记忆被篡改 → 通过数据线索（全息证物、聊天记录）还原被删除的真相。
**AI 亮点**：
- **动态记忆**：NPC 的"记忆"随证据变化——这是 AI 剧本杀独有的、线下做不到的机制
- 证据形态新颖：AI 生成电子证据（邮件、监控文本、代码片段）
- 知乎知识 API：可检索科技/伦理讨论作为案件背景
**盐言 IP 适配**：盐言科幻/悬疑 IP；原创亦可（世界观自建成本低）
**比赛适配**：创意创新性维度最容易拿高分，与同类文字冒险拉开差距。

## 类型五：恐怖惊悚还原本

**定位**：氛围压迫感 + 还原诡异事件真相（非鬼怪，多为人为）。
**核心玩法**：封闭山庄的怪谈 → 玩家轮流搜证触发恐怖叙事 → 还原真相（人性之恶）。
**AI 亮点**：直答 Agent 生成氛围叙事与惊吓点；NPC 行为诡异（一致性守卫反转）
**注意**：内容安全红线——恐怖适度，避免血腥/惊悚过线，Demo 评审需保守
**比赛适配**：氛围型 Demo 传播性强，但安全审核风险需谨慎。

## 类型六：阵营机制本

**定位**：除了还原真相，还有阵营任务、技能、道具的对抗玩法。
**核心玩法**：三方阵营争夺 → 玩家带任务入局 → 技能判定（引擎骰子/属性）→ 阵营胜出结算。
**AI 亮点**：AI 做裁判与 NPC 商人/密探；规则引擎处理任务与技能结算
**开发量**：机制设计 + 数值平衡工作量最大
**比赛适配**：游戏性最强，适合有开发经验的团队；黑客松周期内风险高。

---

## 选型建议

- **求稳冲奖** → 类型一（社会派悬疑）：闭环完整、评审友好、Demo 稳
- **创意突围** → 类型四（科幻脑洞）：记忆篡改机制是"AI 原生"的最佳证明
- **展示 AI 扮演** → 类型二（都市情感）：对话即卖点
- **有视觉团队** → 类型三（古风权谋）：世界观/美术上限最高
