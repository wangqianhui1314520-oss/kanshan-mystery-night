## 1. 世界观

赛博都市「乌托邦市」，人人佩戴记忆芯片（MemChip），可被官方记忆剪辑公司合法付费编辑。网红经济高度发达，「热搜榜」是社会运行的绝对法则——热度即货币，热搜值即社会地位。本局故事发生在年度直播盛典「星夜之夜」前夜。

**核心矛盾**：当所有人的记忆都可以被编辑，你还能相信你记得的"真相"吗？

---

## 2. 故事梗概

顶流主播「阿岚」在盛典前夜被爆出年度大瓜：偷税漏税 + 假人设。瓜引爆热搜，全网沸腾。但 6 位当事人醒来发现——**自己的记忆芯片被人动过手脚**，每人记得的"真相"各不相同，且都很离谱。

距离盛典开场（全网直播）还剩 90 分钟。你们必须在此之前：
1. 搞清楚「瓜的真身」究竟是什么；
2. 找出篡改记忆、操控舆论的幕后黑手。

## 5. 核心机制

### 5.1 热搜值系统（D 核心 · 热榜API驱动）

- **发帖带节奏**：每轮每位玩家 1 次。输入一条带节奏文案 → AI 生成热度反馈（随机系数 0.5-1.5 × 文案质量分）→ 更新全网热搜榜
- **热搜榜实时显示**：当前各"瓜的版本"热度排行（版本A 偷税 / 版本B 假人设 / 版本C 被对家陷害 / 版本D 自导自演）
- **API 接入**：正式版开局调用知乎热榜，取真实热点词条作为"全网吃瓜背景板"；游戏内热搜值 = 本地模拟 + API 热度系数加权
- **结算**：阵营总热搜值 + 真相还原度 → 结局（双结算）

### 5.2 记忆碎片系统（B 核心 · AI生成）

- 每人持有 2-3 块记忆碎片（AI 生成的离谱搞笑记忆片段，如"我记得阿岚在月球开过演唱会"）
- 碎片类型：**真实碎片**（含真相线索，加密）/ **伪造碎片**（AI编造，混淆视听）
- 操作：私聊交易（换/骗/买）｜拼接（两人碎片拼出完整画面）｜回放（AI 生成影视化"记忆小剧场"——本局最大欢乐点）
- 裁判 Agent 记录碎片使用情况，供动态难度参考

### 5.3 实锤搜证系统（规则引擎 · 复用 game 工程）

- 消耗行动力，按"场景 × 条件"从线索池发卡（复用 `engine/evidence_chain.py`）
- 线索卡三级：公开 / 限定 / 隐藏（隐藏需条件触发，如赵四的"交易照片"需先证明玩家可信）
- 线索与真相表绑定（`truth.json`），一致性守卫拦截 AI 编造证据

### 5.4 热搜词条生成器（欢乐点）

- 玩家发帖 → AI 自动生成沙雕热搜词条（如"爆！阿岚偷税漏税还欠外卖钱"）
- 词条实时进入热搜榜展示，制造全网传播感

### 5.5 看山鉴假小游戏（补齐赛制第 3 条）

**机制**：圆桌阶段每轮插入 1 次。刘看山端出 2 段"记忆录像"（AI 生成，一真一假），玩家判定哪段是伪造记忆。

| 判定 | 效果 |
|---|---|
| 正确 | 本阵营热搜值 +5，获得 1 条提示线索 |
| 错误 | 刘看山吐槽（欢乐）+ 全网欢乐值 +1（欢乐值影响结局彩蛋） |

**独立试玩入口**：Demo 首页提供《看山鉴假》轻量试玩版（随机生成真假记忆片段猜真假），单独可玩——直接满足"围绕看山IP延展、适配知乎社区场景的轻量小游戏"。

### 5.6 动态难度系统（补齐赛制第 5 条）

- 每轮末，裁判 Agent 输出**推理进度分** = 证据覆盖率 40% + 正确方向 30% + 活跃度 30%
- **进度 < 30%**：水哥嘴松（证词更直白）、线索提示 +1、隐藏线索提前解锁
- **进度 30-60%**：维持
- **进度 > 60%**：真凶琳姐嘴硬（更会狡辩）、增加 1 张干扰线索（假实锤）、水哥加大强度

**效果**：玩家始终处于"差一点就能破"的紧张感——AI 独立游戏玩法探索的实证，计划书硬加分项。

### 5.7 社交关系链（补齐赛制第 4 条）

- **知乎 OAuth 登录**：AppID/AppKey 接入，登录数据参与赛事人气奖
- **好友房**：拉知乎互关好友组局（关注流 API；MVP 先模拟好友列表）
- **全网吃瓜排行榜**：每局热搜值结算后写入排行榜（评分 + 最快破案时间），好友间竞技
- **MVP 范围**：单机 + 模拟好友榜；正式版：关注流 API + 实时多人

## 6. 多结局分支设计

| 结局 | 触发条件 | 内容 |
|---|---|---|
| **真·瓜熟蒂落** | 指认琳姐 + 动机 + 手法全对，热搜值不低于阈值 | 真相全揭开，琳姐被捕，阿岚洗白 |
| **护瓜成功** | 琳姐未被指认，护瓜派热搜值最高 | 瓜被压下去，但真相沉底（遗憾感） |
| **爆瓜胜利** | 琳姐未被指认，爆瓜派热搜值最高 | 阿岚社死，真凶逍遥 |
| **吃瓜群众赢麻** | 吃瓜派热搜值最高 | 团团赚麻，真相半开（彩蛋） |
| **烂尾** | 无人指认 / 全员跑偏 | 盛典开场，瓜被更大的瓜盖过（幽默结局） |
| **隐藏·真相反转** | 记忆碎片收集 ≥ 80% + 看山鉴假全对 | 触发"阿岚自述"反转剧情，完美真相 |

**结局生成**：AI 动态生成结局文案（结合本局行动日志 + 热搜值 + 真相度），刘看山"配音式"复盘。

## 7. 流程节奏（分幕）

| 幕 | 内容 | 时长 |
|---|---|---|
| 第一幕 破冰·记忆错乱夜 | 选角 → 刘看山开场 → 每人爆料"我记错了什么"（欢乐） | 10min |
| 第二幕 机制轮 ×3 | 每轮 = 发帖 + 交易/搜证 + 看山鉴假 + 动态难度调整 | 30min |
| 第三幕 圆桌·全网开撕 | 互相盘问、实锤公开、记忆拼接 | 15min |
| 第四幕 指认+结算 | 指认黑手 + 热搜值结算 → 结局 | 10min |
| 复盘 | 真相回放（时间线 + 记忆还原对照）、AI 复盘报告、排行榜更新 | 5min |

## 11. 产品计划书要点（社区价值叙事）

- **一句话**：把"热搜、流量、舆论操纵"做成游戏——信息真实性是知乎最核心的议题
- **三个价值点**：
  1. 盐言/原创 IP 互动化：静态内容变成可玩的互动叙事
  2. 知乎 API 真实驱动游戏数值：热榜不只是背景，是玩家的战场
  3. AI 独立游戏玩法：动态难度、AI 记忆生成、AI NPC——不是"AI 套壳聊天"，是规则引擎 + 多 Agent 的完整游戏系统
- **差异化**：欢乐本（传播性）× 机制本（游戏性）× 推理本（深度）三合一，同赛道无同类竞品
