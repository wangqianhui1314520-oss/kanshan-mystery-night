# UI/UX 方案 V2：参考经典游戏 UI 的四个方案（章节独占式框架下）

> 均兼容已定的「章节独占 + 章末点击推进」框架与 actSet 幕门控；差异在舞台呈现语言。每案标注参考原型。

## 方案 1「逆转裁判」对峙式

- 参考：逆转裁判系列
- 布局：左右立绘对峙（嫌疑人 vs 调查员）、中下逐字台词框、证据卡拖拽出示、「异议！」拍桌演出（震屏/惊讶框）；
- 适用：圆桌对质、证伪、指认演出——证据链玩法的表现力天花板；
- 风险：演出量大，逐字机+立绘动画工作量中高。

## 方案 2「十三机兵」分屏叙事式

- 参考：十三机兵防卫圈
- 布局：四面板同屏分格（对话线/心声线/搜证线/舆论线），点击聚焦放大、其余缩略自动滚；
- 适用：三幕机制同屏分格——第二幕心声面板解锁、第三幕舆论面板解锁（面板=幕门控的自然可视化）；
- 优势：信息密度最高，"三线并进"契合章节独占式；锁定面板=雪花噪点「信号加密」。

## 方案 3「杀戮尖塔」手牌式

- 参考：杀戮尖塔/炉石
- 布局：底部扇形手牌=知识卡，拖拽到目标 NPC 身上即使用（语义按章节判定：第2幕=开导/第3幕=辟谣弹药）；中段为章节画面；
- 优势：知识卡的"卡牌感"最强、拖拽交互爽、抽卡滑入动画自然；
- 风险：拖拽交互移动端适配需调教。

## 方案 4「原神」沉浸 HUD 式

- 参考：原神/塞尔达
- 布局：场景真图全屏无框，UI 收进四角极简组件（左上任务/破绽、右上资源、左下对话气泡、右下功能轮盘），NPC 就地头顶气泡；
- 优势：沉浸最强、画面最大、最"游戏感"；
- 风险：功能入口深（收进轮盘），信息密度低。

## 推荐：混合方案（2+1+3）

- **章节舞台主体 = 方案 2 分屏叙事**（三线分格天然对应三幕机制解锁，锁定面板=雪花噪点预告）；
- **对质/指认演出 = 方案 1 对峙式**（第二幕证伪、终局指认切换为对峙舞台）；
- **知识卡 = 方案 3 扇形手牌**（全程层，横跨所有章节画面）；
- 分屏面板聚焦后可全屏化（≈方案 4 的沉浸态用于单面板深潜）。
