# 看山 = DM = 最大隐藏 Boss（双层真相设计）

> 需求：刘看山担任 DM，同时是整个剧本杀最大的隐藏 Boss。
> 关联：STORY_ADAPTATION.md（三幕盐言缝合）、KNOWLEDGE_SYSTEM.md（知识卡）、GAME_DESIGN_V3.md。
> IP 合规：看山形象用官方发放资源；"隐藏 Boss"≠反派——看山是设局的求真侦探，动机正面（钓出污染源），符合 IP 调性与知乎价值观。

## 一、双层真相结构

| 层 | 内容 | 揭晓时机 |
|---|---|---|
| 表层真相（第三幕） | 谁是水军头子、谁动了记忆芯片——玩家互指的阵营答案 | 指认结算 |
| 里层真相（终极层） | **整场对局本身就是看山设的局**：他假失踪、锁大门、扮系统提示音，钓鱼执法钓出污染源，顺便逼 8 个人直面自己被信息污染的"心病" | 集齐 5 个「看山的破绽」后解锁「指认：DM」选项 |

**动机**（正面）：看山发现档案局混入了记忆编辑者，但打草惊蛇——于是自导自演失踪，把所有人锁进"出不去的档案局"，让污染行为在局内自然复发、当场现形。**"你们破的局，正是看山设的局。"**

## 二、DM 人格：刘看山

- 形象：官方看山 IP 资源（建队后领取，先占位）；声音：IndexTTS 2.5 音色（睿智+嘴损+爱吃鱼干）；
- 前三幕人格伪装：DM 以"叮——系统提示音"面目出现（缝合《不提分就出不去的房间》），玩家以为那是档案局的系统；
- 终极层揭晓：系统提示音就是看山本人的声音——**第一幕的【不出真相，不出此门】横幅是他亲手写的**。

## 三、看山的五个破绽（伏笔链，D 组内容锚点）

1. **鱼干口味口误**：第一幕 DM 吐槽里说出只有失踪者才知道的鱼干口味——"你怎么知道？"
2. **最高权限删除**：监控 21:07-21:15 的删除账号 = 档案局最高权限（就是看山）；
3. **主人级签名**：看山Bot V3 被删日志前后有"主人级指令"签名（科技伦理线与 boss 线在此交汇）；
4. **唤醒词彩蛋**：锁门系统唤醒词是"看山，关门"——玩家在对话框试出来触发彩蛋横幅；
5. **策划签名**：复盘页署名列表下有一行小字："本局由刘看山亲自策划——策划你的策划。"

## 四、触发与结局体系（最终 9 结局口径）

- 5 个破绽以隐藏线索形式散布三幕（tier=hidden，条件各异，其中 1 条需知识卡《不想学习的时候如何逼迫自己学习》开导看山Bot 后出现）；
- 集齐 ≥5 → 指认阶段新增选项**「指认：DM 刘看山」**；
- **flavor_5 时序桥接（G04 修复，实跑已验证）**：策划签名线索（clue_032）门控在复盘署名区（review:credits），进入终局投票即视为复盘达成——引擎在 boss 裁决前自动注入该破绽（server/engine_driver.py）。mutation 基线：无注入时 4/5 破绽 → 群嘲结局「你连 DM 都想锤?」，注入后 5/5 → 终极结局可达；
- 结局矩阵更新：

| 结局 | 条件 |
|---|---|
| 完美还原 / 真相大白 / 沉冤得雪 / 污染胜利 | 同 V3 |
| 隐藏·被删的第 7 章 | 盐言彩蛋 5 碎片 |
| 隐藏·全员心晴 | 知识开导 4+（看山自己推门回来认领鱼干） |
| 隐藏·看山的鱼干 | 沉底君好感拉满（boss_key）+ V587 真身揭穿（保留项，与「全员心晴」并存；D 组另设鱼干收藏支线） |
| **终极·看山还是山** | 指认 DM 成功 + 心晴诊室 2+：看山现身承认设局，污染源当场抓获，全员毕业出局——**最大彩蛋：这一局的"局"本身** |

- 「指认 DM」但破绽不足 → 触发群嘲结局"你连 DM 都想锤？"（欢乐向，不惩罚）。
