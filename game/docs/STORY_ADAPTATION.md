## 二、逐幕调整细节

### 第一幕「出不去的档案局」（原：失踪夜）
- 21:00 档案局大门全息横幅亮起：**【不出真相，不出此门】**——21:00 封控，23:00 确认无法解除后开局，致敬原作"强制爱学习的房间"。
- AI DM 更名「系统提示音」人格：每轮开场播报"叮——第 N 轮搜证开始，剩余行动点 3"；玩家吐槽台词可触发【已打码】彩蛋横幅。
- 新增欢乐点：横幅偶尔"抽风"打出错误惩罚（如【惩罚：围观鱼干一分钟】），DM 当场重写。

### 第二幕「心声泄露」（原：记忆碎片）
- NPC 记忆块结构调整为双层：`said`（口供，可被编辑）+ `heart`（心声，被加密）。
- 「记忆修复」技能 → 解锁心声层；**口供与心声对不上的地方 = 篡改点**（证据链核心），玩家"偷听心声"的爽感直接对应原作。
- 看山Bot 特殊：心声层是日志流，V3 段有被删日志（科技伦理线锚点）。
- 引擎接口不变（memory_system 的 blocks 已含 integrity 字段，增加 `layer: said|heart` 即可，B 组按此实现）。

### 第三幕「披着虎皮的猫」（原：热搜疑云）
- 舆论战机制不变（热度值/水军/辟谣）。
- 终局揭面文案定调：水军头子被指认时弹出**「原来你是披着虎皮的猫」**全屏梗横幅。
- V587 身份三层反转的揭示节奏对齐"猫妖→虎崽→真身"：新用户→旧账号→（隐藏真结局身份）。
- 动物拟人世界观合法化：知乎宇宙本来就是拟人都市（看山=北极狐侦探），第三幕解锁全员"动物态"立绘彩蛋（可选，ImageGen 批量生成）。

### 署名与合规（必做）
- 开场载入页与复盘页固定显示：**"剧情设定致敬盐言故事《不提分就出不去的房间》作者灯灯 / 《穿越大明，我被崇祯偷听心声》作者凉风有信 / 《咪假虎威》作者反骨"**。
- 产品说明"使用的知乎开放能力"一节列出：盐言故事 API（改编底座+署名）、知乎知识 API（热搜词条与弹幕素材）、热榜、搜索、直答、OAuth。
