# 《求真档案局·看山失踪夜》线上/线下剧本杀对标与全面优化方向

> 评估对象：`game/` 当前可玩版本（AI 圆桌、搜证、记忆、热搜、知识卡、投票、复盘、多人房间）
> 说明：本报告采用公开行业常识与成熟产品范式做对标，并结合仓库现有设计文档、前端流程与测试发现；不把无法在当前环境实时打开的网页内容当作已验证事实。

## 一、先给结论

当前产品的差异化已经成立：它不是把线下剧本电子化，而是把知乎的“求真、热榜、知识、答主生态”做成了可操作的推理机制。问题集中在三处：

1. **第一局的推理闭环还不够稳定**：玩家可能搜不到关键证据、行动点花完仍无法达到预期结局，导致“我做对了但系统判错”。
2. **机制很多，但主线优先级不够明确**：圆桌、搜证、记忆、诊室、热搜、污染、小游戏、收集品同时出现，容易像功能展厅，削弱案情推进。
3. **AI 的惊喜感已有，复盘和社交传播还不够强**：优秀剧本杀的价值在于结束后仍愿意讨论、复盘、二刷、安利；当前需要把“为什么输/为什么赢”和“我在局中的独特故事”做成可分享结果。

## 二、成熟线上与线下玩法的共性

### 线上产品可借鉴的范式

- **百变大侦探、我是谜、剧本杀 App 类产品**：房间匹配、语音/文字双通道、主持人流程控制、线索按幕解锁、投票结果实时反馈、结算后复盘与评价。
- **狼人杀/推理社交产品**：首轮破冰、发言顺序、私聊、遗言、警长/主持人控场、断线托管、身份信息分层。
- **互动叙事与分支游戏**：短反馈循环、明确目标、选择后立即产生可见后果、关键节点自动保存、失败可解释。

线上产品最值得吸收的是“低门槛上手、短回路反馈、多人协同可见、断线也能继续、局后有持续内容”。

### 线下高口碑剧本杀的范式

- **硬核推理本**：时间线、空间关系、证据链互相咬合；关键结论必须由玩家推出来，主持人只负责节奏。
- **欢乐/机制本**：身份目标清晰，资源争夺、交易、押注、技能和反转形成可重复的回合结构；失败也有节目效果。
- **情感/沉浸本**：角色动机先于谜题，个人秘密、关系和选择让玩家“为角色行动”。
- **阵营本**：公开信息与私密信息分层，阵营目标不完全等于个人目标，允许谈判、误导、跳反，最终复盘解释每个人为何做出选择。
- **演绎本**：开场、幕间、高潮、终局、复盘有清晰舞台节拍，音效/灯光/主持人口播服务于转场，而不是持续堆叠。

线下最值得吸收的是“角色目标驱动发言、证据必须可验证、每幕都有高潮、结算对每个人负责”。

## 三、与当前版本逐项对照

| 能力 | 当前基础 | 行业成熟标准 | 优先优化 |
|---|---|---|---|
| 新手进入 | 已有 6 步引导、案件卷宗、破冰圆桌 | 60 秒内知道自己是谁、要做什么、怎么赢 | P0：把引导改为“第一次行动带教” |
| 主线目标 | 搜证/对话/开导/投票齐全 | 每幕只突出一个主目标，其他机制服务主目标 | P0：做“本幕任务卡” |
| 证据质量 | 公开/限定/隐藏/伪造、地点热度 | 关键证据有保底路径，伪证可被验证 | P0：关键线索保底与证据图 |
| 角色驱动 | 8 角色有腔调、秘密、心病 | 每人至少 1 个必做公开目标 + 1 个私密目标 + 1 个关系目标 | P0：补目标与关系网 |
| 节奏 | 三幕、转场、爆点设计齐全 | 每 8–12 分钟出现可感知变化 | P1：动态节拍器与超时兜底 |
| 多人社交 | party、私聊、AI 补位、断线接管 | 发言秩序、轮次、遗言、主持控场完整 | P1：补轮次/发言权/沉默处理 |
| 结算 | 9 结局、成就、侦探报告 | 每个玩家知道“个人目标、阵营目标、案件目标”完成度 | P0：三层评分与可解释复盘 |
| 二刷传播 | 每日挑战、快速局、收集品 | 分享卡、称号、不同路线、二刷提示 | P1：生成个人高光卡与路线摘要 |

| 可访问性 | 响应式、ARIA、空态、断线反馈 | 语音、文字、低带宽和移动端均可玩 | P1：操作节流、网络恢复提示、文本回放 |

## 四、必须优先修的 P0

### 1. 建立“关键线索保底”

当前设计允许搜证失败、地点热度归零、行动点有限；这对二刷很有趣，但首局会出现证据链断裂。将线索分为：

- **主线锚点**：每幕 2–3 张，至少有两条不同获取路径；
- **推理加分**：用于覆盖率、成就和隐藏结局；
- **欢乐彩蛋**：可以错过，不影响主线。

当玩家在本幕剩余 2AP 仍缺主线锚点时，DM 应给出“方向提示”或开放第二路径。提示只说地点/关系，不直接说答案。

### 2. 让“做对了就能赢”成为硬规则

测试记录已经暴露过终极结局不可达、正确指认真凶仍落全员喷子、关键覆盖率过严等问题。应统一裁决顺序：

`案件命中 → 证据充分度 → 阵营/个人目标 → 隐藏条件 → 欢乐分支`。

案件命中不能被一个过高的覆盖率阈值覆盖掉；覆盖率应影响“完美还原/真相大白”的档位，而不应把正确答案降级为错误答案。多人投票必须消费聚合 tally，不能由最后一位投票者决定结局。

### 3. 把每个角色的目标写到可执行层

8 个角色都应有：

- 开局可见的角色愿望；
- 第一幕必须完成的一件事；
- 只有通过对话/交换/私聊才能完成的关系目标；
- 阵营目标之外的个人胜利条件；
- 复盘时可量化的完成度。

这样能避免玩家只盯着“找凶手”，也能减少 NPC 对话沦为问答接口。

### 4. 重做首局信息架构

首局默认只露出：`圆桌对话 → 本幕任务 → 当前可做行动 → 证物袋`。把小游戏、收集品、广播、证据拼图、成就放到“更多玩法”，在触发条件满足后再出现。当前章节菜单已经有基础，但还需要在视觉和文案上进一步建立主次。

## 五、P1 机制与内容优化

### 证据与推理

- 增加一张可视化**时间线**和一张**关系图**，玩家把线索拖入节点，系统只校验结构，不自动给答案。
- 伪造线索增加三类可验证特征：来源签名、时间冲突、与另一证据的物理矛盾。
- 限定线索支持“展示/隐瞒/交换/拍照留证”四种动作，并在复盘显示每次隐瞒带来的后果。
- 把 `G01/G02/G10/G11` 这类引擎问题变成回归门槛：条件线索必须校验持有状态，重复事件幂等，多人票必须聚合。

### 圆桌与社交

- 每幕使用固定发言轮：自述 → 自由提问 → 指定质询 → 总结；沉默时 20 秒后 AI 给出可选问题。
- 公开频道、私聊、阵营频道分别显示可见范围；所有消息保留“来自谁、何时、是否被篡改”的元信息。
- 增加“引用证据发言”按钮，玩家发言可绑定证据卡，复盘能回放关键争论。
- AI 补位必须有明确行动预算和可犯错边界，避免 AI 过度替真人推理。

### 热搜与污染

- 热度不只是一条数值，拆成“曝光、可信度、情绪”三条，辟谣可以降低曝光但提高可信度，买热搜提高曝光但可能降低可信度。
- 每轮热搜至少出现一个“可验证真帖”、一个“高传播伪帖”、一个“玩家自定义话题”，让玩家做信息判断而不是只点按钮。
- 给求真侧一个同场即时反制窗口，修复当前纯污染策略容易碾压、双方缺少交互的问题。

### 记忆与知识卡

- 记忆修复先展示“我记得什么”，再展示“哪里不一致”，最后让玩家选择相信哪一版；目前的 diff 机制应保留，但增加选择后果。
- 知识卡不应只是收集：每张卡绑定“适用对象、有效证据、错误使用代价”，让抽卡成为推理资源。
- 开导失败也应留下关系变化或新口供，避免消耗 AP 后只有“失败”。

### 演出与节奏

- 开场 90 秒内完成世界观、角色分配、胜利条件和第一项可操作任务。
- 每幕固定三拍：新信息 → 玩家争论 → 强制转场；超时自动触发 DM 事件，防止多人房间卡死。
- 语音只用于关键句和转场，普通内容提供文字回放与倍速，降低等待和带宽成本。

## 六、P2 留存、传播与商业化方向

- 结算生成“我的本局故事卡”：角色、阵营、关键选择、最强证据、最离谱发言、结局、称号；一键导出图片。
- 提供 30 分钟快速局：4 角色、1 条主线、1 次投票，保留“AI DM + 热搜反制”的核心差异。
- 每日挑战不要只换文本，加入“无知识卡”“全员 AI”“污染加速”“盲搜”等规则变体。
- 建立二刷引导：结算页明确显示“你没看到的两条支线”和“下一局推荐角色”。
- 增加主持人/房主工具：跳幕、重发线索、查看玩家是否卡住、静音/暂停 AI、导出复盘。
- 评分体系分开显示：案件推理分、角色目标分、阵营贡献分、知识开导分；不要用单一总分抹平不同玩法。

## 七、建议的落地顺序

### 第 1 个迭代（先保首局成功率）

1. 统一 resolver 的命中、覆盖率、多票聚合口径；
2. 主线锚点双路径 + 低 AP 保底提示；
3. 首局默认信息架构与本幕任务卡；
4. 8 角色目标/关系目标/个人结算字段；
5. 用一条完整“新玩家 45 分钟路径”做验收，而不是只看单元测试。

### 第 2 个迭代（提升多人戏剧性）

1. 发言轮次、质询、引用证据、私聊范围；
2. 热搜三维数值与同场反制；
3. 记忆选择后果、知识卡使用代价；
4. DM 节拍器、超时自动推进、AI 补位边界。

### 第 3 个迭代（做传播与二刷）

1. 个人故事卡与复盘回放；
2. 快速局、每日规则变体、路线推荐；
3. 房主控制台、观战、回放分享；
4. 主线和支线内容扩容，优先增加“不同决策导致不同场景”，而非单纯增加线索数量。

## 八、验收指标

- 新玩家从进入房间到完成第一次有效行动 ≤ 90 秒；
- 首局主线关键证据获取率 ≥ 95%；
- 正确指认不因覆盖率阈值被判为错误；
- 多人投票聚合结果与结局 100% 一致；
- 任一幕卡住超过 2 分钟的比例 < 5%；
- 结算页能在 30 秒内回答：我是谁、我做对了什么、我错过了什么、下一局怎么玩；
- 文本/语音任一通道都能独立完成一局；
- 复盘回放能还原关键证据、关键发言和关键选择。

## 九、最值得保留的产品资产

看山 DM 隐藏 Boss、知乎热搜污染与辟谣、知识卡开导、双层记忆、规则引擎与 AI 分离、失败也有节目效果，这些已经构成清晰的产品识别度。后续扩容应优先让这些机制互相咬合，避免继续横向堆功能。
