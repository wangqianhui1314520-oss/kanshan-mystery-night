# QA 报告：前端游玩全链路压测取证（AI 聊天链路故障定位）

> 日期：2026-09-14 22:00–22:45 · 方式：协议级模拟前端（session→WS→chat 全链路）+ 真实 LLM 调用 + 边界/并发压测
> 取证脚本（只读，均在 `game/tools/`）：`qa_frontend_stress.py`、`qa_flow_probe.py`、`qa_guard_probe.py`、`qa_respond_timing.py`
> 原始数据：`game/data/_qa_stress_report.json`

## 一、结论（TL;DR）

**「AI 聊天聊不起来、回复跟复读机一样」不是大模型的问题——LLM 本身健康（本地直调 7.4~17.8s 返回高质量人设回复）。问题全部出在服务器执行环境与调度管线，共 4 个根因叠加：**

| # | 根因 | 证据 |
|---|------|------|
| 1 | **本机系统代理劫持服务器出网**（ProxyEnable=1 → 127.0.0.1:65532；Python urllib/httpx 默认自动吃系统代理）→ 知乎直答上游 401/405/秒回异常文本交替出现 | health `last_errors.chat="上游返回 HTTP 401"`；压测并发报 `HTTP Error 405`；注册表实读 |
| 2 | **玩家定向私聊触发 9 席 AI 自走棋 wave（串行 LLM，60~100s+）且持锁**，同一 WS 连接消息串行处理 → 后续消息全部排队沉底（连玩家消息回显都不广播） | 事件流探针：Q2/Q3 发出后 32s 无任何回显/回复；wave 轮播每条间隔 6~12s |
| 3 | **LLM 同步调用直接跑在 asyncio 事件循环里**（urllib 阻塞）→ 并发 10 人时事件循环冻结 45s，8/10 客户端 WS keepalive 超时被踢（1011），服务进程一度崩溃（8899 失去监听） | 压测 P3：ok=1/10，fails 全部 1011；事后 `netstat` 无 LISTEN |
| 4 | **两类硬编码兜底句被高频触发**，顶替真实 LLM 回复：`npc_agent.py:146` 身份替换句、`npc_social.py:203` 违规替换句 → 单句复读，玩家感知"AI 是傻子" | 今日 40+ 个 session 存档反复出现同句；NPC 回复延迟仅 224~349ms（不可能完成真实 LLM 往返） |

## 三、通过的项（边界防御OK，无需修）

- 不存在 session WS → `session_not_found` ✓；畸形 JSON/数组/未知 type → 明确 error ✓
- 空文本/超 1000 字 → 明确拒绝 ✓；无效 target → 明确提示 ✓；ping/pong ✓
- 观战只读拦截 ✓；REST 非法 mode 400 ✓；身份泄漏诱导未泄漏产品名 ✓
- LLM 人设质量（干净环境直调）：知之者"先问是不是，再问为什么"口吻在线、能引用时间线自辩 ✓

## 四、修复方案（下一阶段 fix 按 P0→P1 执行，全部零副作用）

1. **P0-1 出网强制直连**：`run.py` 顶部 `os.environ.setdefault("NO_PROXY","*")`；httpx 全部 `AsyncClient(trust_env=False)`；urllib 建 `OpenerDirector` 用 `ProxyHandler({})`——三处封死代理注入面。
2. **P0-2 私聊不触发自走棋 wave**：定向 chat（target=NPC）只走 npc_chat 管线；公开广播才允许 wave；或 wave 改 fire-and-forget 异步任务（结果经 broadcast 推送），绝不阻塞 WS 读循环。
3. **P0-3 LLM 调用全面 `asyncio.to_thread`** 化（对齐 `run_ai_act` 已修复的先例），消灭 `time.sleep`（改 `asyncio.sleep`）。
4. **P0-4 进程守护**：演示机用 `--reload` 关闭 + supervisor/NSSM 托管；健康检查自动拉起。
5. **P1-1 替换句扩池**：两类替换句各扩 ≥6 条 + 随机 + 带角色口吻；`violations` 时优先"重试一次"再降级。
6. **P1-2 事件标签诚实化**：替换句/fallback 事件的 `provider` 标 `fallback:*` 并带 `degraded:true`，前端可提示"AI 线路抖动"。
