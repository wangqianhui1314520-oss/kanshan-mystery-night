# UI/UX 重设计三方案（V4 综艺化 + 按幕解锁）

> 需求：UI/UX 重设计符合综艺游玩流程，该第几幕开启哪些功能就第几幕。三案共用同一套状态机（stages + actSet 幕门控已实现），差异只在呈现层，可后期切换。

## 方案 A「综艺演播厅」（桌面主方案）

- 布局：中央大圆桌全屏常驻（ui_roundtable 铺底+发言聚光灯），顶部节目 HUD 横幅（幕数/热度/破绽/在线），右侧弹幕流栏，**底部操作 Dock 按幕点亮**；
- 幕解锁 UX：Dock 未解锁项显示 🔒+悬浮预告（"心声系统 · 第 2 幕开启"），解锁瞬间全屏横幅+图标点亮动效；
- 优点：最像综艺现场，评委桌面演示冲击力强；缺点：移动端需单独适配。

## 方案 B「章节卷宗」（叙事感方案）

- 布局：顶部三幕卷宗标签条（当前幕高亮、未解锁幕 🔒 半透明+预告），每幕一张全屏主题插画背景（act_t1/t2/t3），左现场区 + 右功能面板堆叠（本幕功能自上而下排列），右侧信息栏（弹幕/证物/资源）；
- 幕解锁 UX：幕切换=翻卷宗动画+新标签页亮起；锁定面板显示"下一幕预告+进度"；
- 优点：叙事感最强、信息密度高、手机竖屏自然适配；缺点：沉浸感略弱于 A，面板层级较深。

## 方案 C「直播流」（移动端优先方案）

- 布局：竖屏 9:16 全屏"现场画面"（圆桌/场景综艺运镜切换）+ 顶部 LIVE 在线数 + 弹幕飘屏层 + 底部**功能抽屉（礼物式按幕上架）**；
- 幕解锁 UX：新功能上架=礼物开箱动效+全屏横幅+点亮音效，锁定=半透明锁标预告；
- 优点：移动端/传播最友好，"看直播玩综艺"概念新；缺点：桌面演示弱，信息密度低。

## 对比与推荐

| 维度 | A 演播厅 | B 章节卷宗 | C 直播流 |
|---|---|---|---|
| 桌面演示冲击力 | ★★★ | ★★ | ★ |
| 移动端体验 | ★★ | ★★★ | ★★★ |
| 叙事沉浸 | ★★★ | ★★ | ★★ |
| 实现工作量 | 中 | 低（结构最接近现状） | 中高 |
| 风险 | 低 | 低 | 抽屉交互新，需调教 |

**推荐组合**：**A（桌面主形态）+ C（≤640px 响应式自动切换为直播流）**——同一状态机两套布局，评委桌面看演播厅，手机看直播流；B 的"锁定面板预告"作为 A/C 通用的解锁 UX 组件。
