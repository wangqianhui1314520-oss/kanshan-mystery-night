# 知乎开放平台 API 接入方案

> 开放平台：https://developer.zhihu.com ｜ 申请 AppID / AppKey
> 工具包：黑客松 Skill 工具包（2026-09-04 版，含盐言故事与知识接口）

## 接口与用途对照

| 接口 | 剧本杀用途 | 日限额 | 缓存策略 |
|---|---|---|---|
| 盐言故事 API | 剧本内容资产：拉取小说世界观/角色/剧情骨架 | 官方黑客松专用**免鉴权**内容接口（`api.zhihu.com/km-indep-home/hackathon/v2`），非开放平台鉴权接口；配额/频控以官方 skill `hackathon-content-api.md` 为准 | 开局一次性拉取入库，全剧复用 |
| 直答 Agent | NPC 对话、DM 叙事、搜证细节生成（核心） | 100 次 | 场景描写/开场白预生成缓存 |
| 知乎搜索 | 案件原型素材、证词素材、背景检索 | 5000 次 | 剧本制作期用，运行期少用 |
| 知乎热榜 | 动态案件原型、热点议题挂钩（可选） | 100 次 | 开局拉取一次 |
| 知乎知识 | 古风典故/科技伦理等背景知识检索 | 同上（黑客松专用免鉴权接口） | 按剧本预检索入库 |

## 直答 Agent 调用模板（示意）

```
POST /api/v4/agent/direct_answer
{
  "question": "扮演雾城旅店老板娘，回答玩家提问「阿岚失踪那晚你看到了什么？」。你的设定：{角色卡 secret/timeline 摘要}。本局你尚未信任玩家，回答需隐瞒货车目击事实。",
  "stream": true
}
```

## 限额管理（必须实现）

1. **预生成缓存**：开场白、场景描写、NPC 固定设定在开局时批量生成入库
2. **运行时节流**：每轮对话只调 1 次；重复提问走本地模板
3. **降级**：超限/超时 → 返回预写剧情兜底，保证对局不断流
4. **提额**：额度不足时向赛事方提交提额申请

## 安全与合规

- 账号登录（OAuth）建议接入：登录数据参与最佳人气奖评判
- 遵守接口使用禁令：禁止高频批量调用、刷屏灌水
- 剧本内容需内容安全过滤（自由对话审核），违规内容由引擎拦截
