## 二、角色表（8 嫌疑人，社区生态拟人）

| 角色 | 拟人原型 | 腔调（AI 人设锚点） | 机制作用 |
|---|---|---|---|
| 知之者 | 资深答主 | 先问是不是，再问为什么；句句带数据引用 | 公开线索源，可信度高 → 反转点 |
| 笔上仙 | 盐言写手 | 说话像小说，动不动"欲知后事" | 盐言彩蛋线入口（剧情底座改编自盐言故事，署名） |
| 流量酱 | 热榜话题精 | 每句话自带 #话题# | 被裹挟执行者（可策反）+ 第三幕水军线 |
| 路人甲 | 匿名吃瓜群众 | "我好像看到过…但我记不清了" | **记忆碎片机制核心**：记忆版本最多 |
| 看山Bot | AI 机器人 | 答非所问 + 逻辑异常诚实 | 科技伦理线；V3 记忆里藏着被删日志 |
| 沉底君 | 折叠区怨灵 | 每句话后缀"[该发言已被折叠]"（实际未折叠） | 欢乐担当 + 隐藏真结局钥匙 |

## 三、搜证阶段详设（怎么搜）

### 3.1 入口：场景图选点
- 前端渲染档案局俯视场景图，**10 个可搜地点**：看山工位 / 服务器机房 / 天台 / 前台 / 茶水间 / 档案室 / 监控室 / 热搜后台 / 空调机房 / 快递柜。
- 每个地点实时显示：剩余热度（三档模糊提示：**有发现 / 可能有 / 一无所获**——由引擎按剩余线索数计算，不直接剧透）。

### 3.2 操作循环（每轮 3 行动点）
```
点地点 → 搜证面板（系统建议 2-3 个关键词 + 自由输入框）
  → 消耗 1 点提交 → 引擎匹配：location ∩ clue.tags ≥ 1 → 从候选池按优先级发线索
  → AI 扩写搜证文本（只许改写 flavor，不许动 fact）+ 弹幕吐槽
```
- **命中**：发放线索卡，进入个人证物袋。
- **未命中**：只发"环境线索"（预置环境描述池，无案情信息）——**AI 永远无法捏造证据**，没搜到就是没搜到，但环境描写负责搞笑。

### 3.3 线索分级（evidence_chain 引擎裁决）
| 级别 | 规则 |
|---|---|
| 公开线索 | 圆桌可展示共享 |
| 限定线索 | 仅获得者可见，**可以说谎、可以藏**（阵营博弈核心） |
| 隐藏线索 | 条件解锁（如：记忆修复到 V3 后出现） |
| 伪造线索 | 污染阵营"投放伪证"技能混入公开池，`fake_of` 指向被篡改的真线索 |

### 3.4 博弈规则
- **地点热度**：每被搜一次热度 -1，归零只剩环境线索 → 抢搜压制；
- **独家猛料**：限定线索全局仅一份，先到先得；
- **搜证冲突**：同一地点同轮被两人搜 → 后来者额外获得"现场被翻动过"痕迹线索（可指证先手）；
- **交叉验证**：两张互斥线索同台 → 触发"证伪对质"（AI DM 主持 mini-game：举证方陈述 → 被指方辩护 → 全场投票，判定由引擎按 truth_node 归属裁决）。

### 3.5 记忆修复（第二幕专属搜证）
- 对 NPC 消耗 2 点使用「记忆修复」→ 引擎解锁其 memory 下一版本（V1→V2→V3）；
- 此后该 NPC 对话口径自动切换（memory_state 注入 prompt，一致性守卫防穿帮）；
- 版本 diff 处自动产出「**篡改点**」线索（高价值，自动入证据链）——多版本对比本身就是搜证。

### 3.6 证据合成与指认
- 集齐 3 条关联线索（`linked_truth_nodes` 有交集）→ 引擎自动合成「证据卡」；
- 指认必须提交 ≥2 张证据卡支撑；Judge Agent 按 truth_node 覆盖度打分 → 决定结局档位。

## 四、欢乐从何体现（七 个欢乐源）

1. **AI 实时弹幕**：每次玩家发言/搜证后，AI 生成 3-5 条知乎热评风弹幕（"前方高能""这波在大气层""建议查查，但不至于删号"）——全程陪伴感，独处开局不冷场。
2. **人设腔调喜剧**：知之者句句"先问是不是"；沉底君每句话被"[已折叠]"（实际没有）；流量酱说话自带 #话题#；AI DM 定期锐评全场。
3. **欢乐热搜词条**：#看山失踪# #谁动了我的鱼干# #档案局空调为什么这么冷#；水军帖一眼假但好笑（"我朋友的同学就是看山，他说他挺好的"）。
4. **搜错地方的彩蛋**：茶水间搜出"半块鱼干 + 纸条：别找了，摸鱼中"；空调机房搜出"二十年前的大力丸"。
5. **失败也是节目**：指认错误 → "全员喷子结局"欢乐复盘，DM 逐个锐评推理翻车现场，不惩罚、有梗。
6. **策反机制**：污染阵营里的"被裹挟者"可被说服跳反（对话达条件触发）——欢乐外壳下的真实阵营深度。
7. **节奏爆点**：DM Agent 控场，每 12-15 分钟设计一个"哦豁时刻"（热搜爆帖 / 记忆反转 / 弹幕玩梗高潮），欢乐与悬疑交替。
