# 知识卡系统：知乎知识 10 篇的结构化用法

> 需求：10 篇知乎知识正文全部结构化进玩法，不是贴皮彩蛋；游戏做大；保持欢乐阵营机制推理本 + AI 原生。
> 源文本：`content/worlds/yanyan_sources/knowledge_*.json`（10 篇全部入库，含正文与作者署名）。
> 关联：STORY_ADAPTATION.md（三幕盐言缝合）、GAME_DESIGN_V3.md（三幕框架）。

## 一、系统总览：「心晴自习室 + 知识卡」

知乎的专业内容在游戏里是**武器和钥匙**——"用知识对抗谣言、用知识开导人心"，正是知乎社区价值（求真、专业、助人）的玩法化。

```
新增搜证地点 #11「心晴自习室」→ 抽「知识卡」（10 张，对应 10 篇正文）
  → 知识卡三种用法：
    ① 知识开导：匹配 NPC「心病卡」→ AI 基于原文生成开导对话 → 解锁心声层/证据/策反
    ② 官方辟谣弹药：第三幕辟谣必须引用匹配的知识卡，引错反被群嘲
    ③ 终局「心晴诊室」：开导数决定结局档位与隐藏结局「全员心晴」
```

## 三、机制细则

### 3.1 知识卡获取
- 地点 #11「心晴自习室」（美术已可生成）：每次搜证消耗 1 行动点，**随机抽 1 张未持有的知识卡**（卡面=该篇标题+作者+金句，背文=原文摘要）；
- 全队共享卡池（公开信息），但**使用时机是私有决策**——藏卡到终局也是策略。

### 3.2 知识开导（AI 原生核心动作）
- 消耗 2 行动点：选 NPC + 选一张知识卡 → 引擎查匹配表：
  - **匹配成功**：AI（自建 LLM，few-shot 注入该篇正文金句）生成一段"知乎式开导"对话——先专业后破防，最后一句必须是原文金句改写（欢乐+温情）；发放收益（见上表）；
  - **匹配失败**：AI 生成"尬聊现场"——NPC 当场愣住、弹幕群嘲（"答非所问预警"），无收益但涨欢乐值；
  - 开导记录进入「心晴档案」，终局展示。

### 3.3 官方辟谣升级（第三幕联动）
- 辟谣技能消耗改为：2 行动点 + **引用 1 张知识卡**；
- 卡与谣言帖的 `topic_tag` 匹配 → 辟谣成功（降热度、解真线索）；
- 不匹配 → 辟谣失败，热搜反涨（群嘲弹幕：**"没知识还硬辟谣"**）——把"专业对抗谣言"变成真机制。

### 3.4 终局「心晴诊室」（新结局层）
- 指认结算后新增复盘环节：按开导成功数结算——
  - 0-1 人：普通结局；
  - 2-3 人：结局 +「心晴档案」放映（欢乐向）；
  - 4+ 人：**隐藏结局「全员心晴」**：看山自己推门回来（"我就是出去买了袋鱼干，你们倒把我局给破了？"）+ 全员开导金句回放；
- 污染胜利结局下诊室变为"扎心大会"（反向欢乐）。
