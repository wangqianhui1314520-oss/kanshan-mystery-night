## 一、核心结论

**不符合。8 条画面里只有 1 条（`prologue`）真正呈现了「谁 + 在哪里 + 干了什么」，其余 7 条全是空场景。**

更根本的问题在于**定位错配**：这批视频被放在「地点氛围层」（`map.js` 的 `.scene-head` 作 LOOP 背景），是合格的；但如果期望它承担「证据画面」职责，则**结构性不成立**——原因见 §四。

| 层级 | 承担什么 | 当前状态 |
|---|---|---|
| **氛围层**（地点 LOOP 背景） | 证明"有这么个地方" | ✅ 基本合格（4 条） |
| **证据层**（线索特写） | 证明"谁在何时何地做了什么" | ❌ **完全缺失**，该职责目前仅由文字承担 |

## 三、三类结构性问题

### 问题 1：全部无人（除 prologue）→ 无法回答「谁」

线索里的行为主体一个都没出现：

| 主体 | 叙事中的行为 | 画面是否呈现 |
|---|---|---|
| 盐值君 | 21:47 在系统留言板留言「检测到异常，建议关注」 | ❌ |
| 路人甲 | 21:15 在快递柜终端完成代签 | ❌ |
| 流量酱 | 21:10–21:25 在 LC-03 工位批量发帖删帖 | ❌ |
| 看山Bot | 22:30 执行「删除 21:07–21:15 备份与自身缓存」 | ❌ |
| 看山（本人） | 全称"失踪"，实际全程在局内 | ❌ |
| V587 | 疑似协从 | ❌ |

**画面能证明"这里是机房"，但证明不了"有人在这里动过主机"。**

### 问题 2：关键信息全是文字载体 → AI 无法呈现

`asset_gen.py:26` 的 `STYLE_PREFIX` 写死「画面中不出现文字」。但线索的关键证据**恰恰全是文字**：

| 线索 | 证据本体 |
|---|---|
| clue_001 | 横幅文案 + 字体渲染参数 |
| clue_003 | 锁门日志 + 「建议关注」留言 |
| clue_009 | 时间轴空洞 + 账号 KS-000 |
| clue_011 | 快递单「寄件人缩写 KS」 |
| clue_012 | 清单页脚「矩阵_K 监制」 |
| clue_013 | 指令头「主人级」+ 哈希 A3F9-77C2 |
| clue_016 | 封禁公告 + 背面铅笔字 |
| clue_028 | 鱼干口味「彩虹鳟鱼」标签 |

**约束与需求直接冲突**：要文字就违反 STYLE_PREFIX；不要文字就丢失证据。

### 问题 3：实测 AI 会"抗命"造字 → 反而制造假证据

`clue_001_banner` 是活证据：即使 STYLE_PREFIX 声明不出现文字，画面顶部仍生成了**幻觉汉字「北庭析国」**。

危害等级最高——**这等于在证据链里凭空植入了一条错误信息**，玩家会试图解读这四个字。这比"画面空着"严重得多。

### 问题 4：时间线不对齐

游戏时间锚点：`21:00 封控` / `21:07–21:15 删监控` / `21:10–21:25 批量发帖` / `21:15 代签` / `21:20 机房高负载` / `21:47 盐值君留言` / `22:30 Bot 删除`。

画面实测：`prologue` = 07:02、`clue_009` = 00:01。**全部无对齐**，而"时间线互证"正是本作核心推理机制。

## 四、能力边界结论（关键）

**AI 生视频不适合承担「证据画面」职责。** 三条硬理由：

1. **文字必乱**：实测已出现幻觉汉字，无法可靠承载日志/单据/时间码
2. **精度不可控**：账号、时间码、哈希值这类必须逐字准确的信息，扩散模型无法保证
3. **不可复现**：同 prompt 每次结果不同，无法回归验证

**与之相对，AI 生视频在「氛围层」是称职的**：`loc_locker` 的红灯、`loc_ac` 的冷雾、`prologue` 的狐狸，都完成得很好。

### 建议的分层方案

| 层 | 承载内容 | 技术路线 | 理由 |
|---|---|---|---|
| **氛围层** | 地点 LOOP 背景 | ✅ AI 生视频（现有方案） | 无文字、无精度要求，AI 表现最好 |
| **证据层** | 日志界面 / 时间轴 / 快递单 / 聊天记录 / 留言板 | ✅ **前端 UI 渲染**（HTML/CSS）+ AI 只出「底图质感」 | 文字逐字可控、零幻觉、可回归测试 |
| **人物行动层** | "谁在何时何地做了什么" | ⚠️ AI 生视频**仅用于无文字的动作剪影**（如监控里闪过的人影） | 有 prologue 成功先例，但不含文字 |

**优先级建议**：先做**证据层 UI 化**。它同时解决"文字精度"和"证据保真"两个问题，且成本远低于重生成视频——因为线索文案（`fact`）已经在数据层写好了，只需把它渲染成"看起来像物证"的界面。
