# frontend（E 前端组管辖）

Vue3 单页 + WebSocket 事件驱动。事件协议见 `docs/CONTRACTS.md` §3.6/3.7。

## 必做界面

1. **场景图**：11 地点选点搜证（地点热度三档提示：有发现/可能有/一无所获）；
2. **对话流**：与 AI DM（看山系统音）/ NPC 对话，弹幕层实时吐槽；
3. **个人证物袋**：线索分级展示（公开/限定/隐藏/伪造）+ 知识卡图鉴（10 卡收集）；
4. **记忆修复/开导演出**：said/heart 双层对比视图、篡改点高亮、开导对话演出；
5. **热搜面板**：每轮刷新、买热搜/辟谣操作、热度值仪表；
6. **圆桌投票**：指认提交（≥2 证据卡）；破绽 5/5 时动态出现**「指认：DM」**按钮；
7. **心晴诊室**：开导结算 + 金句回放；
8. **复盘页**：真相回放、双层揭晓（Boss 层全屏演出）、盐言/知识署名区。

样式基调：深色档案局 HUD + 知乎蓝（#0084FF）点缀，移动端适配。
美术资源：`content/assets/images/`（立绘/场景已生成，命名与场景 id 对应）。
